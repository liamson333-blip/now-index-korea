Live composite. The NOW score is computed from the six factor engines across the full KOSPI/KOSDAQ universe. Each engine returns a 0–100 percentile rank and the engines are weighted (0.25·Valuation + 0.20·Momentum + 0.20·Quality + 0.15·Risk + 0.10·Macro + 0.10·Sentiment) into a single 0–100 composite. Engines whose historical price feed is unavailable (Momentum, Risk) currently use a neutral 50 default so the composite remains robust; these become active once the chart feed is added.

About the project

This repository collects, normalizes, and analyzes Korean market data using a NOW-style index approach. The site demonstrates an open-source landing page for the project.

  • Full KOSPI & KOSDAQ coverage crawled from NAVER Finance
  • Simple, transparent NOW index computation in Python
  • GitHub Pages site for live publishing

How it works

Every KOSPI and KOSDAQ stock is fetched from NAVER Finance with its fundamentals (PER, PBR, EPS, dividend yield, foreign ownership, analyst targets), then scored by the six-factor NOW composite and ranked across the full universe.

  • scripts/fetch_full_data.py crawls & enriches all KRX stocks
  • scripts/generate_site_data.py computes the multi-factor NOW score
  • notebooks/krx_analysis_template.ipynb is ready for analysis

Data source

All KOSPI and KOSDAQ stocks are crawled from NAVER Finance. The repository includes a Python crawler (fetch_naver_data.py) and a PowerShell fallback for systems without Python.

Open source

Everything is available in the GitHub repo, with CI tests and site deployment included.
