About the project

This starter repository is built to collect, normalize, and analyze Korean market data with a NOW-style index approach. The site demonstrates an open-source landing page for the project.

  • Sample data pipeline using KRX ticker fetches
  • Simple index computation in Python
  • GitHub Pages site for live publishing

How it works

The live preview uses hardcoded sample prices to show how an index metric might be displayed. Actual KRX data is supported through the repository Python package and scripts.

  • scripts/fetch_krx_data.py downloads KRX stock history
  • src/now_index_korea/index.py computes the index
  • notebooks/krx_analysis_template.ipynb is ready for analysis

Data source

KRX stocks pulled via Yahoo Finance using ticker suffix .KS. The repository supports sample data and real-world downloads.

Open source

Everything is available in the GitHub repo, with CI tests and site deployment included.
