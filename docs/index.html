How to use

  • Run python scripts/fetch_krx_data.py to download Korean market data.
  • Open notebooks/krx_analysis_template.ipynb to analyze KRX results.
  • Compute a custom index with src/now_index_korea/index.py.

Deployment

This site is configured for GitHub Pages from the repository docs/ folder.
